# Heltec V4 companion · V4: рабочая ветка

Это незавершённая реализация дизайна V4. Прошивку из этой ветки нельзя считать проверенной: сборка ESP32 и проверка устройства ещё не выполнены.

## Что внесено

- Для Heltec V4 задан круг основных экранов V4; батарея, питание и сведения размещены в настройках, сведения внизу. Вложенный заголовок использует `./`, на основных экранах показываются время и процент батареи.
- Экран радио использует крупную частоту, блок параметров и NF; история сбрасывается при смене радиопараметров. GPS показывает количество спутников, шкалу, высоту и координаты; без фикса координаты скрыты, скорость пока не предоставляется источником и показывается прочерками.
- В меню и списках действий один клик выбирает следующую строку, двойной — предыдущую или выход с первой строки. Добавлены безопасные подтверждения поиска частоты, переключения интерфейсов и режима питания. ADC по мультиметру редактируется по цифрам и проверяется перед применением.
- Существующие защитные механизмы радио, калибровка и раздельные настройки RX Boost/FEM LNA сохранены. Доступные пункты зависят от конфигурации сборки и платы.

## Что осталось

1. Собрать `heltec_v4_oled_companion_usb_ble_wifi` в доверенной среде и исправить ошибки компиляции, если появятся. Попытка локальной сборки была остановлена проверкой безопасности при загрузке toolchain: после несовпадения checksum установщик переключился на HTTP-зеркало.
2. Сверить все 113 состояний из макетов: эта ветка пока не реализует каждый диалог. В частности, просмотр сообщений, отдельные варианты профилей/маяка, некоторые подтверждения и часть оформления пока используют прежнюю логику. Не считать поведение во всех подэкранах совпадающим с макетами V4.
3. Проверить на устройстве навигацию, отрисовку на OLED и обновление NF, подключение BLE/Wi-Fi/USB, восстановление радио после сканирования, вход в CLI rescue и сохранение калибровки ADC после перезагрузки.
4. Скорость GPS требует расширения `LocationProvider`; до этого показывается `--.-km/h`.

Проверка синтаксической структуры выполнена на тексте C++ после предварительной обработки с конфигурацией V4 без подключаемых заголовков. Это не компиляция и не проверка типов или прошивки на плате.
