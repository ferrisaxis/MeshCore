# Heltec V4 companion · состояние реализации V4

PR №9 объединяет исходный перенос интерфейса и реализацию Иосифа из `ab596491`.

В объединённом варианте есть круг из 12 экранов, заголовки `./Название`, главная со статусом связи, счётчики сообщений, IP на экране связи, количество соседей и отдельный выбор языка. Питание, батарея и сведения находятся в настройках. Для поиска частоты, смены интерфейса, режима питания и радиопрофиля предусмотрено подтверждение. Опорное напряжение для калибровки по мультиметру вводится по цифрам.

## Сообщения и маяк

- Удержание на «Главной» или «Сообщениях» открывает список из 32 последних локальных сообщений. Новые сверху, рядом с отправителем показан возраст и отметка непрочитанного. В длинном тексте один клик листает вперёд, два — назад. С первой страницы два клика возвращают к списку.
- Удержание в тексте открывает действия «Следующее», «Прочитано», «Сведения» и «Удалить из просмотра». Удаление требует подтверждения. История OLED хранится в памяти до перезагрузки. Чтение и удаление локальной копии не меняют очередь телефона. Синхронизация телефона не очищает историю OLED.
- В «Маяке» есть отдельные пункты «Режим», «Получатель», «Интервал» и «Остановить». Для получателя доступны настроенные каналы, восемь недавних личных контактов и ранее сохранённый контакт. Для активного канального или личного маяка список показывает только получателей соответствующего типа. При выключенном маяке выбор получателя сохраняет его для соответствующего режима.
- Для канала и личного маяка доступны 5, 10, 15, 30, 60 и 120 минут. Интервалы хранятся отдельно. У локального и Flood-объявления фиксированные интервалы 10 и 30 минут. Остановка требует подтверждения.

## Шапка, поля и возврат на главную

- Заголовок, время и процент заряда стоят на одной базовой линии. В шапке OLED заложены поля по 3 пикселя вокруг текста. Длинные названия сокращаются по ширине с многоточием.
- Входящие сообщения пополняют историю и счётчики, не меняя открытый экран, не включая погашенный дисплей и не продлевая его таймаут.
- Четыре клика с любого открытого экрана возвращают на главную. Подтверждения и редактор АЦП закрываются без применения. Активный поиск частоты останавливается и восстанавливает радио. На погашенном дисплее первый жест включает экран.

## Проверка

Иосиф сообщил об успешной сборке `ab596491` для `heltec_v4_oled_companion_usb_ble_wifi`, запуске на плате и сохранении коэффициента АЦП после перезагрузки. [Отчёт о проверке](https://github.com/ferrisaxis/MeshCore/pull/9#issuecomment-6707054667)

Иосиф собрал и прошил `790dae47`, проверил запуск и сохранение коэффициента АЦП по USB. [Отчёт о сборке и плате](https://github.com/ferrisaxis/MeshCore/pull/9#issuecomment-6707463752)

Перед слиянием собрать текущий коммит PR и записать его SHA. На OLED проверить возврат из списков и меню, выбор языка, GPS без фикса, восстановление частоты после отмены сканирования и сохранение поцифровой калибровки АЦП.

Для шапки проверить длинные заголовки на русском и английском, 100% и прочерки. Для четырёх кликов проверить просмотр сообщений, вложенное подтверждение, редактор АЦП и активный поиск частоты. Проверить, что личные и групповые входящие оставляют открытое меню на экране.

Для новых экранов проверить пустой список, длинное входящее сообщение, получение ещё одного сообщения во время чтения, удаление локальной копии до синхронизации с телефоном, выбор получателя при выключенном маяке, смену интервала и сохранение настроек маяка после перезагрузки.

## Расхождения с макетами

- В шапке длинного сообщения номер страницы со знаком `+` означает, что текст продолжается.
- GPS показывает прочерк вместо скорости, поскольку текущий источник GPS её не передаёт.
